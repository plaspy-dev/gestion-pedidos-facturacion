# Gestión de pedidos y facturación / Order and invoicing management

[Español](#español) · [English](#english)

## Español

Programa de escritorio para llevar catálogos y convertir un pedido en una factura. Reúne la información comercial que se vuelve a usar en cada operación.

### Qué puedes hacer

- Consulta los formularios de clientes, proveedores, vendedores y productos.
- Captura el pedido y consulta el detalle de los productos.
- Revisa los formularios de facturación y usuarios.

### Ejemplo

Usa un cliente inventado y un pedido de cinco cuadernos. Recorre los formularios de producto, pedido y factura.

### Cómo empezar

El programa se creó en Visual Basic 6. Los formularios conservan referencias a controles y recursos que requieren el entorno de la época. Crea una base local nueva para practicar con datos inventados.

Puntos de entrada en el código. [`Pmm.vbp`](Pmm.vbp).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

A desktop program for maintaining catalogs and turning orders into invoices. It keeps the commercial records that are reused across transactions.

### What you can do

- Review customer, supplier, salesperson, and product forms.
- Enter an order and review its product line items.
- Explore the invoicing and user forms.

### Example

Use a fictional customer and an order for five notebooks. Follow the product, order, and invoice forms.

### Getting started

The program was written in Visual Basic 6. Its forms retain references to controls and resources that require the original environment. Create a new local database for practice with fictional data.

Entry points in the source. [`Pmm.vbp`](Pmm.vbp).

History dates come from Git or available backup evidence. Reconstructed dates from files with no time zone use 12:00 UTC as a reference.
