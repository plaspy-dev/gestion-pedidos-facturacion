# Gestión de pedidos y facturación / Order and invoicing management

[Español](#español) · [English](#english)

## Español

Programa de escritorio para llevar catálogos y convertir un pedido en una factura. Reúne la información comercial que se vuelve a usar en cada operación.

### Esta revisión

**2005-12-01 · Pasar del pedido a la factura.** Recupera los formularios Visual Basic de cliente, proveedor, producto, pedido y factura. Agrupa los datos comerciales que se reutilizan cuando un pedido se prepara para facturar.

### Cómo explorar el código

El programa se creó en Visual Basic 6. Los formularios conservan referencias a controles y recursos que requieren el entorno de la época. Crea una base local nueva para practicar con datos inventados.

## English

A desktop program for maintaining catalogs and turning orders into invoices. It keeps the commercial records that are reused across transactions.

### This revision

**2005-12-01 · Turn orders into invoices.** Recover the Visual Basic forms for customers, suppliers, products, orders, and invoices. Group the commercial information reused when an order is ready for invoicing.

### How to explore the source

The program was written in Visual Basic 6. Its forms retain references to controls and resources that require the original environment. Create a new local database for practice with fictional data.
